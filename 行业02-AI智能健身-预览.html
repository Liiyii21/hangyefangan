01STEP ONE

项目规划/ PROJECT PLAN

// define · positioning · feature scope · tech stack

i
本步骤目标：让 AI 准确理解一款"AI 智能健身 C 端 App"的产品定位、目标人群、核心功能与差异化。建议在 Cursor / Windsurf 中直接粘贴本步提示词作为项目首条 system 指令。
// 工程脚手架 · 通过 pnpm create next-app@latest 初始化，配 App Router + TypeScript strict + TailwindCSS v3 + shadcn/ui + Framer Motion，体测拍照走 getUserMedia() + WASM ImageMagick 压缩至 800KB 以内，AI 调用封装为 useScan() Hook 统一对接 Face++ + TF PoseNet，训练视频走 HLS 流媒体 + video.js。

1.1 产品定位 // 一句话讲清楚做什么

面向 22-40 岁城市白领与健身新人 的 AI 体态体测 + 个性化训练 + 私教转化 平台。用户上传 3 张照片（正/侧/背）即可获取专业体态评估报告，匹配 14/28/56 天训练计划，并可一键预约平台认证私教课程或添加教练微信进行 1V1 服务。

1.2 核心功能模块 // 6 大模块

AI 体测：单图体态分析（高低肩、骨盆前倾、X/O 型腿、含胸等 12 项指标）+ 体脂率估算 + 三维体型重建
训练计划：基于体测结果的 14/28/56 天 AI 训练计划，每日 4-8 个动作，含视频示范与计数
动作识别打卡：摄像头实时识别动作标准度，AI 计数 + 鼓励语音 + 分数
私教课程：认证教练库、单次/课程包/月卡、在线预约 + 到店扫码核销
转化引流：支付成功后自动展示 教练专属微信二维码，进入私域 1V1 服务
成长体系：训练记录、体测对比、成就徽章、连续打卡天数（PK 与社区可选）

1.3 技术栈与 AI 能力 // stack

前端：Next.js 14 App Router · TypeScript · TailwindCSS · Framer Motion · Lucide React · react-webcam（拍照） · MediaPipe / TensorFlow.js（动作识别）
AI：Face++ / 商汤 体态分析 API · 通义千问-VL 多模态生成训练建议 · 自训练 YOLO 姿态检测
后端：Next.js API Routes · Supabase（用户/订单/打卡）· 微信支付 V3 · 阿里云 OSS（视频）
