01STEP ONE

项目规划/ Project Plan

// positioning · users · scope · stack · compliance

i
本步骤目标：让 AI 准确理解一款"AI 智能玄学命理 C 端 App"的产品定位、目标人群、核心服务体系与 合规边界（不算命凶 · 引导积极）。
// 工程脚手架 · 通过 pnpm create next-app@latest 初始化，配 App Router + TypeScript strict + TailwindCSS v3 + shadcn/ui，命盘绘制走 SVG + Framer Motion，毛笔字效果用 ZCOOL XiaoWei 字体 + text-shadow 萤光，排盘内核 lunar-typescript 已 tree-shaking 减包至 18KB，填充争议内容走 Sentry 实时上报保证合规边界。

1.1 产品定位 // one sentence

面向 22-45 岁都市女性与高知人群 的 AI 八字 / 紫微 / 塔罗 / 姓名学命盘解读 + 命理大师 1V1 解盘 + 改运法器开光 平台。用户输入出生信息或抽取塔罗牌，60 秒生成结构化命理报告（含五行 / 性格 / 财 / 情 / 健康 / 大运），可一键预约 860+ 认证命理师 进行视频解盘，并选购改运法器、定制开光物件。

1.2 核心服务模块 // 5 services

八字命盘：四柱八字 + 五行强弱 + 十神 + 大运流年
紫微斗数：天盘、地盘、人盘 + 命宫十二宫 + 主星副星
塔罗牌阵：牌阵选择（单张 / 三张 / 凯尔特十字）+ AI 解读
姓名学：三才五格 + 五行喜忌 + 起名 / 改名建议
风水占卜：家居风水 / 办公风水 / 流年方位

1.3 合规底线 // must-have

显著标注："命理仅作参考，命运掌握在自己手中"。禁止凶煞断言（不出现"短命""破财"等绝对负面用语）。禁止夸大宣传"包灵验""百分百准"。用户隐私：出生信息加密存储，不对外公开。广告法：不出现"最准""第一""唯一"等绝对化用语。

1.4 技术栈 // stack

前端：Next.js 14 · TypeScript · TailwindCSS · Framer Motion · D3.js（命盘绘制）
AI：通义千问 / DeepSeek 命理专项微调 · 八字排盘算法 · 紫微斗数算法库 · 塔罗 78 牌图像库
后端：Next.js API · Supabase · 微信支付 · 农历转换库（lunar-javascript）· 经纬度数据库
