01STEP ONE

项目规划/ Project Plan

// positioning · users · scope · stack · compliance

i
本步骤目标：让 AI 准确理解一款"AI 智能法律咨询 C 端 App"的产品定位、目标人群、核心功能与合规底线。建议在 Cursor / Windsurf 中直接粘贴本步提示词作为项目首条 system 指令。
// 工程脚手架 · 通过 pnpm create next-app@latest 初始化，配 App Router + TypeScript strict + TailwindCSS v3 + shadcn/ui 组件库 + Framer Motion 动画。AI 调用层封装为 useStreamChat() Hook，统一兼容 DeepSeek / 通义千问 / GPT-4 三家供应商，方便成本对账与故障切换。

1.1 产品定位 // one sentence

面向 25-50 岁中产人群与中小企业主 的 AI 案情评估 + 律师 1V1 咨询 + 文书代写 平台。用户输入案情描述后 60 秒内获得 AI 风险评估报告（含胜诉率、风险等级、法条引用、类似案例），并可一键预约平台 3260+ 认证律师 进行电话/视频/到所咨询，亦可购买专业法律文书模板。

1.2 核心功能模块 // 6 modules

AI 案情评估：多模态输入（文字/语音/拍照合同），自动识别案件类型，生成结构化报告
风险报告：胜诉率预测 / 风险等级 / 关键法条引用 / 类似裁判案例 / 维权路径建议
律师匹配：按业务领域、地域、价格、评分智能推荐 3-5 位最匹配律师
咨询服务：3 种方式（电话 ¥800/h、视频 ¥1200/h、到所 ¥3000/h），按时计费
文书购买：380+ 法律文书模板（合同/起诉状/答辩状/律师函），AI 自动填充 + 律师审核
转化引流：支付成功后自动展示 律师助理微信二维码，进入私域 1V1 服务跟进

1.3 合规底线 // must-have

显著标注："AI 报告仅供参考，不构成法律意见"。律师执业证必须真实可查（与司法部接口对接）。禁止保证胜诉。用户信息加密，案情数据不上链。广告法：不出现"最权威""第一""保证"等绝对化用语。

1.4 技术栈 // stack

前端：Next.js 14 App Router · TypeScript · TailwindCSS · Framer Motion · Lucide React
AI：通义千问 / DeepSeek / GPT-4 法律专项微调 · 北大法宝 / 威科先行 法条数据库 · 中国裁判文书网检索
后端：Next.js API · Supabase · 微信支付 · 阿里云身份认证 · 实名制 + 律师证 OCR
