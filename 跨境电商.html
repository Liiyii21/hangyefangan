01FOUNDATION

规划 · 人群 · 合规 · 技术栈

合规红线

六条不可逾越的边界

①
不操作用户账户　平台严禁以任何形式代客登录、代投广告、代操作店铺后台,所有操作权限留存卖家本人(参照各平台服务协议 API 使用条款及《电子商务法》第 38 条平台责任界定)
②
不参与刷单测评　禁止协助用户组织虚假订单、违规激励评论、刷好评等操控行为,AI 输出中涉及评价获取策略须自动过滤违规建议(亚马逊 Community Guidelines、《反不正当竞争法》第 8 条)
③
不承诺 GMV 增长　禁用"保证翻倍""稳定 ROI xx%""无效退款"等承诺性话术,所有 AI 预测输出须附 90 天置信区间与数据局限性说明(《广告法》第 4 条真实性原则)
④
数据合规 · GDPR / CCPA　处理欧盟用户数据须取得明确同意,数据最小化采集,用户有权随时申请删除,跨境数据传输须通过标准合同条款(SCC)或充分性认定(《个人信息保护法》第 38-40 条及 GDPR Art.6)
⑤
海关合规 · 申报真实　平台不得协助用户低报货值、伪报品名、拆单逃税,AI 清关建议须以真实交易价格为基准(海关总署《跨境电子商务零售进出口商品监督管理办法》第 11 条)
⑥
知识产权边界　选品分析模块不得建议用户仿制、贴牌已注册商标商品,AI 输出自动比对 USPTO / EUIPO 商标数据库,高风险品类触发合规警告(《商标法》第 57 条及亚马逊 Brand Registry 规则)

03AI CORE

AI 核心模块 · 三层编排设计

TradeNova 的 AI 不是单点问答，而是「感知—分析—围栏」三层闭环：选品雷达持续感知全球市场信号，经营顾问深度分析店铺健康，安全围栏在法律与专业边界处守门。三层之间通过统一的 Prompt 路由层衔接，任意一层失败均有明确降级路径，不对用户产生误导性输出。

模块一 · 选品雷达 AI（MarketRadar）

跨平台商机感知与选品决策辅助

①
作用　每日扫描亚马逊 / 速卖通 / TikTok Shop 三平台 BSR 榜单及搜索词趋势，自动聚合需求上升 ≥ 30%、竞争密度评级「低 / 中」、毛利空间预估 ≥ 25% 的品类，生成「今日 20 个高潜品类」简报，支持按站点 / 品类 / 价格带筛选。
②
Prompt 摘要　系统提示词锁定角色为「跨境电商市场分析师」，输入变量包含：目标站点、用户历史选品偏好、当前在售 SKU 列表；要求输出结构化 JSON（品类名 / 需求指数 / 竞争指数 / 利润区间 / 切入建议）；禁止输出「一定能赚」「稳定收益」等承诺性表述；每条结果末尾强制附数据来源与采集时间戳。
③
失败兜底　若第三方平台 API 返回超时（P99 阈值 5s），降级为展示 T-1 缓存数据并标注「数据更新于 xx 小时前」；若 Claude 推理超时，回退到规则引擎输出预设模板简报，不展示空白或错误态。
④
合规边界　所有利润预估标注「仅供参考，实际利润受 FBA 费率、汇率波动、平台政策调整影响」，禁止在输出中引用未经核实的竞品店铺销售额数据，防止违反《反不正当竞争法》关于虚假宣传的相关条款。

模块二 · 经营顾问 AI（BizAdvisor）

店铺健康诊断与经营决策对话

①
作用　接入用户授权的店铺 API 数据（GMV / ACoS / 库存周转 / 净利润率），结合 BGE-M3 向量检索「最相似的 500 个历史店铺案例」，由 Claude Sonnet 生成个性化经营建议；支持自然语言提问，如「我的广告预算怎么分配」「FBA 备货量如何设置」，上下文窗口维持最近 20 轮对话。
②
Prompt 摘要　系统提示词注入当前店铺实时指标快照（刷新间隔 ≤ 15 分钟）、用户会员等级（决定可调用的分析深度）、历史对话摘要（由 GPT-4o 每 10 轮压缩一次）；输出格式要求：建议条目 ≤ 5 条、每条附置信度（高 / 中 / 低）与预期影响量化值；禁止输出「你应该立刻」「必须」等强指令性语气。
③
失败兜底　Claude 调用失败时，切换至 GPT-4o 备用通道，SLA 保障对话服务可用率 ≥ 99.5%；若两路模型均不可用，自动触发「人工顾问排队接入」提示，等待时长承诺 ≤ 4 小时（工作日）；所有降级事件写入审计日志，按月向用户披露。
④
合规边界　平台不持有跨境电商经营许可，AI 建议定性为「经营参考」而非「专业咨询意见」；涉及税务申报、海关申报等法定事项，强制展示「建议咨询持牌税务师 / 报关行」提示，不替代专业资质判断（依据《电子商务法》第 38 条平台责任条款）。

模块三 · 行业安全围栏 AI（SafeGuard）

危机词识别 · 强制导流 · 转人工 · 不替代专业判断

①
危机词识别　维护一份动态危机词库（当前 1,240 条），涵盖：平台封号危机词（「刷单」「测评互换」「变体合并操控」）、法律风险词（「假冒品牌」「侵权链接」「洗钱」「逃税」）、极端情绪词（「崩了」「破产了」「活不下去」）；词库每周由合规团队人工复核更新，版本号可追溯；命中阈值：精确匹配即触发，语义相似度 ≥ 0.85 亦触发。
②
强制导流与转人工　触发平台合规类危机词 → 自动中断 AI 对话，展示「该问题涉及平台政策风险，AI 无法作答，已为你匹配持牌跨境合规顾问，预约响应时效 ≤ 2 小时」；触发法律风险词 → 强制弹出法律顾问预约入口，同时向后台合规团队推送告警；触发极端情绪词 → 暂停经营建议输出，切换为「人文关怀」模式，展示心理援助热线（全国心理援助热线 400-161-9995）并通知客服主动外呼。
③
不替代专业判断声明　每次会话开始前展示一次、每 30 轮对话强制重新确认：「TradeNova AI 提供经营数据分析与参考建议，不构成法律意见、税务意见或投资建议；平台不具备律师事务所、税务师事务所或投资顾问资质；具体决策请咨询持牌专业人员。」用户须点击「我已知晓」方可继续，确认行为写入操作日志留存 5 年。
④
输出二次审核　SafeGuard 作为独立微服务，对 MarketRadar 与 BizAdvisor 的所有输出内容进行 100ms 内的实时过滤；过滤维度：违规承诺词 / 竞品诋毁词 / 虚假数据词 / 涉政敏感词；过滤命中率目标 ≥ 99.2%（以季度内测数据为基准），漏检事件 72 小时内人工复盘并更新词库。
为什么这套 AI 编排可信赖　三层模块各司其职且相互制衡：MarketRadar 只做「看见」，BizAdvisor 只做「分析」，SafeGuard 负责「守门」——任何一条输出在到达用户之前，都必须经过围栏层的二次审核。失败兜底路径覆盖率 100%，不存在「AI 崩了用户看到空白」的裸奔场景。更关键的是，平台在合规文件与用户协议中明确「AI 不替代专业判断」，将责任边界写进合同而非藏在角落，这才是跨境电商 SaaS 在《电子商务法》与《生成式人工智能服务管理暂行办法》双重框架下真正可持续运营的底气。
