01STEP ONE

项目规划/ Project Plan

// positioning · users · scope · stack

i
本步骤目标：让 AI 准确理解一款"AI 智能家居整装 C 端 App"的产品定位、目标人群、核心功能与差异点。
// 工程脚手架 · 通过 pnpm create next-app@latest 初始化，配 App Router + TypeScript strict + TailwindCSS v3 + shadcn/ui，整屋 3D 走 three.js + react-three-fiber + R3F Drei，户型扫描封装为 useScanRoom() Hook 统一对接 YOLOv8 与 SAM 分割模型，渲染任务走 BullMQ 异步队列防 GPU 资源争抢。

1.1 产品定位 // one sentence

面向 28-45 岁新房装修业主与改善型家庭 的 AI 拍房识图 + 整屋 3D 设计 + 设计师上门服务 平台。用户拍一张房间照片，60 秒识别户型尺寸、当前风格、家具空缺，AI 自动生成 整屋 3D 方案（含 18-32 件家具），可一键整屋组合购或预约 2580+ 认证设计师 上门量房。

1.2 核心功能模块 // 6 modules

AI 拍房识图：单图识别户型/面积/层高/风格/光照，自动生成 3D 模型
整屋 3D 方案：基于风格偏好 AI 推荐 6 套整屋方案，可旋转预览
整屋组合购：18-32 件家具一键加购，享套餐价（比单品省 ¥10,000+）
设计师服务：认证设计师库、上门量房（¥299 抵 ¥2000）、整装方案出图
转化引流：支付成功后展示 设计师专属微信，进入私域 1V1 服务
到家服务：免费送货 + 安装 + 30 天无理由退换 + 5 年质保

1.3 技术栈 // stack

前端：Next.js 14 · TS · Tailwind · Three.js（3D 户型渲染）· react-webcam
AI：百度 EasyDL 户型识别 · 通义千问-VL 风格分析 · Stable Diffusion ControlNet 室内重绘 · ARKit / ARCore 实景试摆
后端：Next.js API · Supabase · 微信支付 · 阿里云 OSS（3D 模型/素材）

03STEP THREE

核心闭环 · 整屋 3D 方案/ AI Core

// the moment of trust

★
这是产品最关键的"价值时刻"——用户拍完房间后 60 秒看到一份完整 3D 整屋方案 + 家具清单 + 套餐价 + 省了多少钱。方案越精美、越懂客户、越有节省感，付费转化率越高。
// AI 渲染实现 · 用户拍完裸房后，前端调用 POST /api/furniture/render，后端先走 YOLOv8 户型检测 识别面积 / 朝向 / 层高，随后交给 Stable Diffusion XL 配合 ControlNet (MLSD + Depth) 双控制生成 4K 整屋渲染图，准确保留原始门窗位置与透视结构；同时在成品库内以 cosine similarity 匹配风格、预算与面积都合适的家具清单，下单后自动拆单推送至工厂 SAP 与仓储 WMS，60 秒内输出报价与交付周期。
