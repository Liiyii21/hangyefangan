1.1 产品定位 // one-sentence

面向 22-40 岁都市白领与高校学生 的「轻量级心理陪伴 + 专业咨询入口」。日常用 AI 树洞 倾诉与 情绪日记 复盘建立长期陪伴感（免费），出现持续低落、失眠、关系困扰时无缝转持证心理咨询师 1V1（按时长付费），订阅 冥想课 沉淀习惯与商业留存。

1.2 目标人群 // 3 personas

都市白领（70%）：25-35 岁，月薪 1-3 万，互联网/金融/医护，主诉睡眠差 / 焦虑 / 职场关系，对咨询师价格敏感但愿为效果付费
高校学生（22%）：18-25 岁，主诉学业压力 / 恋爱 / 原生家庭，对 AI 树洞依赖度最高，付费意愿低但用户黏性最高
慢病康复人群（8%）：抑郁/焦虑/双相已就医，需要日常情绪记录辅助主治医生评估，不可作为诊疗工具，仅作生活陪伴

1.3 核心商业闭环 // 5-screen funnel

免费层：注册 → PHQ-9/GAD-7 量表评估 → AI 树洞无限对话 → 情绪日记打卡。付费层 ①：咨询师匹配 → 文字 ¥199/30min · 视频 ¥800/50min · 到诊 ¥1500/50min · 套餐 10 次包 ¥6800（省 ¥1200）。付费层 ②：冥想课会员 ¥39/月（睡前 / 焦虑 / 专注 / 自我接纳 4 大主题，每周更新 2 条音频课）。

合规底线 · 四条红线（最高优先级）

①

03AI CORE

AI 树洞 · 情绪图谱 · 危机干预AI Companion & Safety Net

这一步决定产品的灵魂 —— 一个温柔但理智的 AI 倾听者，不会越界，也绝不冷漠。

🌳任务说明：实现 AI 树洞的对话引擎、情绪日记的结构化记录、30 天情绪图谱的可视化、以及实时危机干预的旁路逻辑。AI 必须在"共情 → 澄清 → 引导自助 → 必要时转人工"四步框架内输出，绝不主动给出诊断或药物建议。
// AI 引擎 · 主模型 DeepSeek-V3，备模型 Qwen-72B-Chat（断流自动切换）。system prompt 模板按用户首选流派（cbt / mindfulness / act）注入，temperature: 0.6，top_p: 0.9，max_tokens: 600。每条消息走双管线：① 主回复用 SSE streaming 推回前端；② 旁路同一段文本喂给 BERT-crisis 二分类器，p > 0.85 立即触发 onCrisisDetected() 中断 AI、弹出 SOS 卡。

3.1 AI 树洞对话引擎 // chat engine

四步框架　每条 AI 回复必须按 共情 ② 澄清 ③ 引导自助 ④ 兜底转人工 的顺序生成；禁止第一句就给建议，必须先复述用户感受让其感到"被听见"。
记忆机制　近 10 轮对话保留全文，超出部分用 BGE-M3 向量化存入 pgvector，每次对话前通过 cosine similarity 召回 top-3 相关历史片段拼入 prompt，营造"它真的记得我"。
多模态输入　支持文字、语音（Whisper 实时转录）、照片（BLIP-2 描述天气/食物/宠物作为情绪线索）；语音消息保留原始波形方便用户回听。
禁忌输出库　硬编码 120 条禁忌回复模板（"你只是想多了" / "别人比你更惨" / "想开点"），moderation API 二次过滤，命中即重生成。

3.2 情绪日记 · 结构化记录 // emotion diary

每篇日记由 { mood: 1-10, emotions: string[], events: string[], body: string, photos: url[], gratitude: string } 组成。emotions 用预设 32 个细颗粒情绪词（焦虑 / 委屈 / 释然 / 内疚 / 期待 …），不让用户面对空白输入框。BERT 自动从 body 抽取 事件触发词（"加班" / "和爸妈吵架" / "体检"）入 events，方便后期生成"压力源排行榜"。

3.3 情绪图谱 · 30 天可视化 // mood graph

① 热力日历：13×30 网格按日 mood 着色（雪松绿 = 平稳，雾蓝 = 低落，晨曦粉 = 愉悦）；② 情绪标签云：词频前 20 个 emotion 按大小分布；③ 压力源 Top 5：events 聚合排行；④ 周报告：每周日早 8 点 GPT-4o 一句话总结："这周你出现 4 次焦虑高峰，多发生在周二早晨 — 是不是周一晚没睡好？"

危机干预 SOP（最高优先级 · 每条消息必跑）

①
检测层　BERT-crisis 模型（基于 2.4w 条标注语料微调）+ 关键词正则双保险，置信度 ≥ 0.85 即视为高危。
②
中断层　立即 abort() 当前 AI 输出流，移除已显示的部分回复，全屏渐入安全卡（雾蓝半透明蒙层 + 月光图）。
③
引导层　卡上同时呈现：北京心理援助 010-82951332、全国 12320、立即联系值班咨询师（自动接通）三个一键按钮，并配一句"你愿意先深呼吸三次吗？"。
④
跟进层　对话上下文 AES-256 加密推送至 SOS 队列，值班咨询师 5min 内主动外呼；用户每 24h 自动收到一条温柔回访 push。

4.1 智能匹配引擎 // 7-step questionnaire + AI recall

7 步问卷　step1 困扰类型（情绪 / 关系 / 创伤 / 成瘾 / 性 / 自我认同 / 其他）→ step2 紧迫度（一周内必须谈 / 这个月内 / 慢慢来）→ step3 流派偏好（CBT / 精神动力 / 接纳承诺 / 家庭 / 萨提亚 / 不懂让 AI 帮选）→ step4 性别偏好 → step5 价格区间（≤ 300 / 300-600 / 600-1000 / 不限）→ step6 咨询模式（文字 / 语音 / 视频 / 到诊）→ step7 时段。step3 不懂时显示一段 60 字流派科普 + AI 推荐按钮。
召回算法　therapist_profile_vec 表用 BGE-M3 把每位咨询师的 主诉范围 + 流派 + 个人风格自述 + 5 篇科普文 拼接成 1024 维 向量入库，用 HNSW 索引；用户查询走 SELECT id, 1 - (vec <=> $1::vector) AS sim FROM therapist_profile_vec ORDER BY vec <=> $1::vector LIMIT 50。冷启动：如果用户首次评估 PHQ-9 ≥ 15，自动跳过流派偏好步，强制推荐有抑郁主诉资质的督导级咨询师。
重排规则　业务层 matchRerank(top50)：流派 +20 / 性别 +8 / 价格 +10 / 当周可约 +12 / 30 天好评率 > 95% +6 / 同语言（粤语/英语 等）+5 / 用户曾收藏 +3。同分时按"最近 7 天接单数 升序"，避免热门咨询师永远排第一。
反操纵　咨询师不能付费买排名，平台只接受平台抽佣（25%）；问卷答案与匹配日志全量入 match_audit_log，每月由合规审计抽查，发现异常排序立即下架算法节点回滚。
